# Website memory

This folder is the durable handoff record for the personal website. Read it before making future changes so prior decisions are not lost between conversations.

## Files

- `PROJECT_CONTEXT.md`: current architecture, design direction, page map, and maintenance rules.
- `CONVERSATION_SUMMARY.md`: concise record of the user’s requests, preferences, and decisions.
- `CHANGELOG.md`: user-visible changes and the decisions behind them.

## Update rule

Whenever a website change is accepted, add a short dated entry to `CHANGELOG.md`. Update `PROJECT_CONTEXT.md` when architecture, deployment, navigation, content structure, or visual direction changes.

Do not record passwords, tokens, private keys, personal conversations unrelated to the website, or temporary debugging details.
