# Zilin Chen — Personal Website

A hand-written multi-page portfolio built with plain HTML, CSS, and JavaScript.
There is no framework, site generator, package manager, or compilation step.

The site includes independent Home, About, Education, Research, Skills, Performances,
Calendar, and Contact pages, plus research and performance detail pages.

Home/Research use `portfolio.css` and `portfolio.js`. Other pages use `styles.css`,
`script.js`, and `i18n.js`. Update both the English HTML and corresponding Chinese
copy when editing content. The graphite/gray design was approved on 2026-10-24.

## Preview locally

Open `index.html` directly, or serve the folder with any static file server.

## Publish with GitHub Pages

In the repository settings, choose **Pages → Deploy from a branch**, then select
the `main` branch and the repository root.
